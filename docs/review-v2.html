Новые находки: злой и добрый ревьюер

Что нашлось в самих правках. Злой ревьюер докапывается, добрый объясняет, как лучше. Оба обращаются к кандидату.

1Новый баг: дисбаланс округляется несимметрично

src/app/format/format-metric.ts:24-28

function formatRatio(value: number): string {
  const rounded = Math.round(value * 100) / 100;
  const normalized = rounded === 0 ? 0 : rounded;
  return ratioFormat.format(normalized);
}
Злой

Стакан 350/450 показывается как -0.12, а зеркальный 450/350 — как +0.13. Math.round округляет половинки вверх, а значит отрицательные — к нулю. С новой моделью стакана, где сумма около 800, такие половинки реально встречаются. Тест проверяет 0.2, -0.2 и -1/1999, но ни одной половинки.

Добрый

Просто удали две строки. Intl.NumberFormat с maximumFractionDigits: 2 сам округляет симметрично, а signDisplay: 'exceptZero' уже превращает -0.00 в 0.00. И добавь в тест пару ±0.125 — именно такие граничные значения ловят подобные ошибки.

2Повторный Apply после незагрузившегося воркера висит вечно

Злой

Если скрипт воркера не загрузился, onerror честно покажет «Не удалось запустить Web Worker». Пользователь идёт в Settings и жмёт Apply, а start() отправляет сообщение мёртвому воркеру: объект воркера не null, поэтому ветка с ошибкой не срабатывает. Ответа не будет никогда, и UI навсегда застрянет на «Запуск генератора…». Сбой конструктора ты закрыл, а этот путь — нет.

Добрый

После ошибки на стадии старта завершай воркер и создавай новый при следующем start(), а если не поднялся и он — сразу отдавай failed. Это и есть довод в пользу отдельного воркера на каждый прогон из v1: там этот случай исчезает сам собой. Туда же относится пересоздание Wasm-модуля после паники: сейчас освобождается только объект генератора, а сам модуль и его память используются дальше.

В документации по-прежнему написано «Третьего звена нет», а проверка обязательности просто переехала в IntegerLink. Chain of Responsibility, ради которой всё затевалось, нарушена первой же правкой. А -5 получает «Ожидается целое число», хотя это целое число, просто вне диапазона, — проверил в браузере.

Добрый

Либо честное третье звено RequiredLink, либо — что лучше — одна функция валидации поля на шесть строк. Для -5 разреши знак в регулярке (/^-?\d+$/) и передай значение в проверку диапазона. Тогда пользователь увидит «Допустимый диапазон 1–50».

Приложение: как воспроизвести

  1. Соберите генератор: npm run build:wasm — появится public/market-wasm.
  2. Дрейф цены: сохраните первый скрипт в корень репозитория как drift.mjs и запустите node drift.mjs из корня. Около 15 секунд.
  3. Округление дисбаланса: сохраните второй скрипт в корень как fmt-check.ts, соберите ./node_modules/.bin/esbuild fmt-check.ts --bundle --platform=node --format=esm --outfile=fmt-check.mjs и запустите node fmt-check.mjs.
  4. Свежая копия: скопируйте рабочее дерево без node_modules, wasm/market-producer/target, public/market-wasm, dist и .angular, поставьте зависимости и запустите npm test. Для проверки без Rust уберите ~/.cargo/bin из PATH.
  5. Бенчмарк и браузер — как в приложении к v1.
drift.mjs — дрейф цены, спред и дисбаланс на настоящем генераторе 
import { readFileSync } from 'node:fs';
import { initSync, MarketGenerator } from './public/market-wasm/market_producer.js';

const { memory } = initSync({ module: readFileSync('./public/market-wasm/market_producer_bg.wasm') });
const STRIDE = 7;

function run(seed, instruments, updatesPerBatch, batches) {
  const names = Array.from({ length: instruments }, (_, i) => 'I' + i);
  const gen = new MarketGenerator(seed, names);
  const touchedFloor = new Uint8Array(instruments);
  const lastBid = new Int32Array(instruments).fill(10_000);
  let minBid = Infinity;
  let maxBid = 0;
  let maxSpreadToPrice = 0;
  let maxSpreadCents = 0;
  let absImbalanceSum = 0;
  let events = 0;
  let zeroDepth = 0;
  const imbalanceBuckets = new Uint32Array(21);
  for (let b = 0; b < batches; b++) {
    const ptr = gen.fillBatch(updatesPerBatch);
    const view = new Int32Array(memory.buffer, ptr, updatesPerBatch * STRIDE);
    for (let i = 0; i < updatesPerBatch; i++) {
      const o = i * STRIDE;
      const idx = view[o];
      const bid = view[o + 3];
      const ask = view[o + 4];
      const bq = view[o + 5];
      const aq = view[o + 6];
      lastBid[idx] = bid;
      if (bid <= 1) touchedFloor[idx] = 1;
      if (bid < minBid) minBid = bid;
      if (bid > maxBid) maxBid = bid;
      const spread = ask - bid;
      if (spread > maxSpreadCents) maxSpreadCents = spread;
      const ratio = spread / bid;
      if (ratio > maxSpreadToPrice) maxSpreadToPrice = ratio;
      const depth = bq + aq;
      if (depth === 0) {
        zeroDepth++;
      } else {
        const imb = (bq - aq) / depth;
        absImbalanceSum += Math.abs(imb);
        imbalanceBuckets[Math.min(20, Math.floor((imb + 1) * 10))]++;
      }
      events++;
    }
  }
  gen.free();
  let acc = 0;
  let p95 = 0;
  const total = events - zeroDepth;
  // p95 |imbalance| по гистограмме с шагом 0.1
  const absBuckets = new Uint32Array(11);
  imbalanceBuckets.forEach((count, k) => {
    absBuckets[Math.min(10, Math.abs(k - 10))] += count;
  });
  for (let k = 0; k <= 10; k++) {
    acc += absBuckets[k];
    if (acc / total >= 0.95) {
      p95 = (k + 1) / 10;
      break;
    }
  }
  return {
    floorCount: touchedFloor.reduce((a, v) => a + v, 0),
    lastBid: Array.from(lastBid),
    minBid,
    maxBid,
    maxSpreadToPrice,
    maxSpreadCents,
    meanAbsImbalance: absImbalanceSum / total,
    p95AbsImbalanceUpTo: p95,
    zeroDepth,
  };
}
