# Файлы без шапки в исходнике

У файлов `.ts`, `.html`, `.scss`, `.rs` и `.toml` шапка «Зачем / Что делает» стоит первой строкой самого файла. Здесь перечислены файлы, где такой комментарий нельзя поставить или он не ставится, потому что файл порождён инструментом.

## Конфигурация npm и Angular

### package.json

Зачем: фиксирует зависимости Angular и команды, которыми проект собирают и проверяют.

Что делает: описывает `npm start` (сначала Wasm, потом приложение), `npm test` и `npm run test:generator`.

### package-lock.json

Зачем: фиксирует точные версии npm-зависимостей, чтобы установка была повторяемой.

Что делает: хранит дерево пакетов, которое создал npm. Вручную не редактируется.

### angular.json

Зачем: говорит CLI, как собирать, раздавать и тестировать приложение.

Что делает: указывает вход `src/main.ts`, стили, каталог `public` и билдер unit-тестов.

### tsconfig.json

Зачем: общий strict-профиль TypeScript для приложения и тестов.

Что делает: включает `strict`, DOM и ссылки на `tsconfig.app.json` и `tsconfig.spec.json`.

### tsconfig.app.json

Зачем: отделяет компиляцию приложения от тестов.

Что делает: включает `src/**/*.ts` и исключает `*.spec.ts`.

### tsconfig.spec.json

Зачем: даёт тестам типы Vitest, не таща их в сборку браузера.

Что делает: подключает `vitest/globals` и файлы `*.spec.ts`.

### .prettierrc

Зачем: один стиль кавычек и ширины строки для людей и для форматирования.

Что делает: включает одинарные кавычки, ширину 100 и парсер Angular для HTML.

## Редактор и git

### .editorconfig

Зачем: выравнивает отступы и перевод строки между редакторами.

Что делает: задаёт UTF-8, пробелы и размер отступа 2.

### .gitignore

Зачем: не даёт закоммитить зависимости и порождённые каталоги.

Что делает: скрывает `node_modules`, `dist`, кэш Angular, `wasm/market-producer/target` и `public/market-wasm`.

### .vscode/extensions.json

Зачем: подсказывает расширения редактора для этого репозитория. Файл создан Angular CLI.

Что делает: рекомендует расширение Angular Language Service.

### .vscode/launch.json

Зачем: конфигурация запуска отладчика, созданная CLI.

Что делает: описывает запуск Chrome для `ng serve` и для отладки тестов. В коде приложения не участвует.

### .vscode/tasks.json

Зачем: задачи сборки CLI внутри редактора.

Что делает: описывает фоновые задачи `npm start` и `npm test` для панели задач.

## Статика

### public/favicon.ico

Зачем: у вкладки есть значок, чтобы документ не запрашивал отсутствующий файл.

Что делает: отдаёт стандартную иконку, которую положил Angular CLI. На метрики не влияет.

## Rust

### wasm/market-producer/Cargo.lock

Зачем: фиксирует версии крейтов генератора, в первую очередь `wasm-bindgen`.

Что делает: записывает точное дерево, которое разрешил Cargo. Комментариев в lock-файле нет.

## generated: public/market-wasm

Каталог создаёт `wasm-pack build --target web`. Его нет в git: `npm start` и `npm run build:wasm` собирают его заново. Шапок «Зачем / Что делает» в этих файлах нет.

### public/market-wasm/market_producer.js

Зачем: клей между TypeScript и модулем Wasm.

Что делает: экспортирует конструктор `MarketGenerator`, метод `fillBatch` и функцию `init`, которая компилирует `.wasm`.

### public/market-wasm/market_producer.d.ts

Зачем: типы клея для компилятора TypeScript.

Что делает: описывает класс генератора и `InitOutput.memory`, не добавляя логики.

### public/market-wasm/market_producer_bg.wasm

Зачем: сам скомпилированный генератор.

Что делает: содержит машинный код шага цены. Его читает воркер через `init`.

### public/market-wasm/market_producer_bg.wasm.d.ts

Зачем: объявление модуля для импорта байтов Wasm, если сборщик пойдёт этим путём.

Что делает: помечает файл как `WebAssembly.Module`. Приложение грузит байты через `fetch`, а не через этот импорт.

### public/market-wasm/package.json

Зачем: npm-манифест, который wasm-pack кладёт рядом с клеем.

Что делает: называет пакет `market-producer` и указывает входной JS. Приложение этот пакет не публикует.

### public/market-wasm/.gitignore

Зачем: локальный ignore внутри каталога пакета, его пишет wasm-pack.

Что делает: прячет внутренние артефакты упаковщика. Весь каталог и так исключён корневым `.gitignore`.

## generated: wasm/market-producer/target

Зачем: рабочий каталог Cargo.

Что делает: хранит объектные файлы `cargo test` и промежуточный wasm перед упаковкой. В репозиторий не входит.
